# Dandle Recliners - Progressive Web App (PWA) Configuration

## Overview

The Dandle Recliners application has been successfully configured as a Progressive Web App (PWA) with full offline support, installability, and native-like experience.

## PWA Features Implemented

### 1. Web App Manifest
- **File**: `public/manifest.webmanifest` (auto-generated in `dist/manifest.webmanifest`)
- **Features**:
  - App name: "Dandle Recliners"
  - Short name: "Dandle"
  - Description: "Premium recliners where comfort meets sophistication"
  - Theme color: White (#ffffff)
  - Display mode: Standalone (full-screen app-like experience)
  - Start URL: "/" (root of the application)
  - Scope: "/" (entire application)

### 2. Service Worker
- **File**: `dist/sw.js` (auto-generated by vite-plugin-pwa)
- **Features**:
  - Automatic precaching of all static assets
  - Network-first strategy for navigation
  - Offline support with cached assets
  - Automatic cache updates
  - Workbox integration for advanced caching strategies

### 3. App Icons
- **192x192px**: `public/pwa-icon-192.png` - Used for home screen icons
- **512x512px**: `public/pwa-icon-512.png` - Used for splash screens and app stores
- **Apple Touch Icon**: `public/apple-touch-icon.png` (180x180px) - iOS home screen
- **Favicon**: `public/favicon.ico` - Browser tab icon

### 4. Meta Tags
- Apple Touch Icon link for iOS support
- Theme color meta tag for browser UI customization
- Manifest link in HTML head

### 5. Service Worker Registration
- Automatic registration via `virtual:pwa-register` in `src/main.tsx`
- Immediate registration with auto-update capability
- TypeScript support with type definitions in `src/pwa.d.ts`

## Build Configuration

### Vite Configuration (`vite.config.ts`)
```typescript
VitePWA({
  registerType: "autoUpdate",
  includeAssets: ["favicon.ico", "apple-touch-icon.png", "pwa-icon-512.png"],
  manifest: {
    name: "Dandle Recliners",
    short_name: "Dandle",
    description: "Premium recliners where comfort meets sophistication",
    theme_color: "#ffffff",
    icons: [
      { src: "pwa-icon-192.png", sizes: "192x192", type: "image/png" },
      { src: "pwa-icon-512.png", sizes: "512x512", type: "image/png" },
      { src: "pwa-icon-512.png", sizes: "512x512", type: "image/png", purpose: "any maskable" }
    ],
  },
})
```

## Installation Instructions

### For Users

#### On Desktop (Chrome, Edge, Brave)
1. Visit the application URL
2. Look for the "Install" button in the address bar
3. Click "Install" to add the app to your desktop
4. The app will open in a standalone window

#### On Mobile (Android)
1. Visit the application URL in Chrome
2. Tap the menu (three dots)
3. Select "Add to Home screen" or "Install app"
4. The app will be added to your home screen

#### On iOS
1. Visit the application URL in Safari
2. Tap the Share button
3. Select "Add to Home Screen"
4. The app will be added to your home screen

### For Developers

#### Building the PWA
```bash
npm run build
```

This command:
- Bundles the React application
- Generates the service worker (`dist/sw.js`)
- Creates the web manifest (`dist/manifest.webmanifest`)
- Copies all assets including icons

#### Running in Development
```bash
npm run dev
```

#### Previewing the Production Build
```bash
npm run preview
```

## PWA Capabilities

### Offline Support
- All static assets are precached by the service worker
- The app works offline with cached content
- Network requests are attempted first, then fall back to cache

### Installation
- Users can install the app on their device
- App appears as a native application
- Can be launched from home screen or app drawer

### App-like Experience
- Runs in standalone mode (no browser UI)
- Custom theme color
- Splash screen support
- Full-screen capability

### Update Management
- Service worker automatically checks for updates
- New versions are downloaded in the background
- Users are notified of updates (can be customized)

## Testing the PWA

### Using Chrome DevTools
1. Open Chrome DevTools (F12)
2. Go to the "Application" tab
3. Check "Service Workers" to see registration status
4. Check "Manifest" to verify manifest configuration
5. Check "Storage" to see cached assets

### Lighthouse Audit
1. Open Chrome DevTools
2. Go to the "Lighthouse" tab
3. Run an audit with "PWA" category selected
4. Review recommendations

### Offline Testing
1. Open DevTools → Application → Service Workers
2. Check "Offline"
3. Reload the page
4. The app should still load from cache

## Troubleshooting

### Service Worker Not Registering
- Check if the app is served over HTTPS (required for production)
- Clear browser cache and service worker cache
- Check browser console for errors

### App Not Installable
- Ensure manifest.webmanifest is accessible
- Verify all required manifest fields are present
- Check that icons are accessible and valid

### Offline Not Working
- Verify service worker is registered
- Check "Storage" in DevTools for cached assets
- Ensure assets are in the precache list
